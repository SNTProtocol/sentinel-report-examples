# Sentinel Public Roadmap

This roadmap distinguishes demonstrated work from proposed work. It is not a release-date or partnership commitment. Internal tasks, customer records and private implementation are excluded.

## Done

- Publish a synthetic report format and runnable offline summary example.
- Publish a small interactive review demo adapted from the investigation prototype.
- Demonstrate case selection, observations versus unknowns, review notes and local history.
- Verify browser save/reload and case separation; nine offline tests pass locally.

These milestones demonstrate synthetic workflows only, not a production insurance service.

## In progress in the wider project

- Validate the hosted institutional report workflow after an upstream RPC failure. Authenticated report creation, idempotent retry and retrieval still need end-to-end acceptance evidence.
- Refine Ethereum/EVM payment-intent evidence and its limits for potential design partners.

## Planned / subject to validation

- Agree evidence requirements and a single pilot use case with a potential insurance design partner.
- Evaluate provenance, freshness, missing-data behavior and independent corroboration requirements.
- Define pilot acceptance criteria before committing to scope or dates.

No confirmed insurer partnership, underwriting validation or launch date is claimed.
